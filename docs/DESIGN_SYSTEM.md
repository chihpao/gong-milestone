# 設計系統

## 設計方向

網站採用「日系動畫作品集 × 滿版文字場景」。手機優先，參考 Izumi Tanaka 網站的全視窗首屏、固定輕量導覽、大量留白與連續滿版內容，但不複製其圖像或程式碼。

## 視覺原則

- 暖白背景、近黑文字與單一冷調薄荷綠強調色；不使用橘紅。
- 全站改用無襯線字體。標題與正文使用 Noto Sans TC，年份使用 Montserrat。
- 事件使用直接相接的滿版場景；桌面只增加日期與內容的橫向層次，不改成交錯時間軸。
- 不使用卡片、圓角、陰影或背景紋理。每個里程碑使用一張與事件直接相關的抽象線性 SVG 插圖，作為內容的一部分而非裝飾圖示。
- 2017 場景例外使用使用者提供的 `2017_animation.svg` 外部本地資產，以裁切方式鋪滿整個事件，使用純白背景及高對比黑白顯示，不疊加綠色遮罩；其他場景維持 inline SVG。
- 里程碑文字只能來自 `CONTENT_SOURCE.md`。

## 互動

- 所有尺寸使用固定站名、右上角漢堡按鈕與全螢幕年份選單。
- 首次開啟顯示極簡四碼入口，不重複顯示站名；「四位數密碼」以淡色 placeholder 放在輸入框內，輸入正確後淡出，並在同一分頁工作階段保持解鎖。
- 手機首屏高度為 `20svh`（最低 120px），桌面為 `25svh`（最低 180px）；`SCROLL` 直向字（`writing-mode: vertical-rl`，低透明度）搭配動態細線引導捲動，桌面字級略大。
- 手機里程碑使用左上日期、左圖右文的兩欄網格；短事件高度約為 `26svh` 且不低於 200px，長內容由文字自然撐高。
- 手機日期、SVG 與內文分屬獨立網格區域，不得互相遮蓋；插圖尺寸及位置在所有事件保持一致。
- 桌面場景使用約五分之四視窗高度；所有日期以相同字級放在左上角，SVG 從日期下方開始，日期、插圖與文字不得互相遮蓋。
- 內文只在該場景進入主要視區後以輕微位移淡入，離開主要視區後再次隱藏。
- 里程碑內容區不使用分隔橫線。
- 2020/03—2023/11 使用房子與水平線的合併構圖，承接疫情返台及留在台灣兩段內容。
- 2024/09-2025/05 使用聚光燈與引號的合併構圖，同一場景承載課程、每月稱讚及老師引言。
- 2024/09-2025/05 場景中的課程、每月稱讚、老師標示與引言共用相同的響應式正文大小；可保留顏色與字重差異，但不得以字級製造層級。
- 最後祝福放在 `Shitty but proud.` 同一場景，以較小字級及較長延遲輕柔浮現；桌面版標語從左上內容位置開始。
- 旅程點、太陽、波浪、洗衣機滾筒等可有低強度循環動態，但不得干擾閱讀。
- 場景離開視窗後重置動畫，重新進入時可再次畫出。
- `prefers-reduced-motion` 時停用動畫並直接顯示完整插圖及內容；列印模式同理。
- 場景保留鍵盤焦點、觸控與 A4 列印支援。

## 響應式

- 360px 起使用精簡首屏及滿寬事件場景；短事件高度為 `max(26svh, 200px)`，內文字級不小於 16px。
- 760px 起放大滿版插圖與內容留白，但仍使用漢堡選單並維持單向閱讀。
- 760px 起首屏使用 `25svh` 且不低於 180px；事件場景為約 `82svh` 且不低於 620px。
- 桌面內容最大寬度 1160px，正文最大寬度約 608px。
- `html`、`body`、固定導覽、選單及內容容器不得超過視窗寬度；長文字必須安全換行。
- 滿版 SVG 同時受視窗寬度與高度限制，必須完整留在自身場景及可視範圍內；事件內容留白需包含裝置安全區。

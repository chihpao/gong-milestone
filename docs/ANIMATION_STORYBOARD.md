# 十一幕動畫製作規格

最後更新：2026-09-24，補齊逐幕創作腳本與未來新增規則。

本文件是現行動畫方向、週期、循環和未來創作方法的製作規格。`data/milestones.json` 將每一幕的日期、內文、年份段、HTML 色調、`assets/animations/` SVG 資產與完整動畫資料綁在同一個物件；其中 `animation.script`、`contentRelationship`、`composition`、`storyBeats`、`style`、`palette`、`timing`、`direction`、`camera`、`motionLayers`、`loop` 是逐幕創作紀錄。舊版恐龍、30–36 秒電影長鏡等紀錄僅存於 CHANGELOG，不再代表現行資產。

`animation.name` 與其他動畫欄位都是製作註記，不是網站可見標題；不得把它們渲染成新的事件文案。

## 共通規則

- 11 幕均為本地 SVG，viewBox 1440×800，SMIL 從資產載入後持續循環，不由捲動或文字開關暫停／重播。
- 主體完整穿越與環境視差保留；平移採線性，肢體與擺動採非線性。定位、旋轉、縮放分層，避免取代底層 transform。
- 循環以畫外退場、等寬重複圖層或首尾透明完成；不能僅憑 repeatCount 判定接點無縫。
- 介面暖白／近黑／薄荷綠維持。使用者在本次驗收明確接受現有 SVG 的橘／紅橘色，保留既有配色。
- 無腳本、外部圖片或網路引用。減少動態與列印由 index.html 顯示靜態備援。
- 手機 360／390／430px 優先；桌面延伸。實機流暢度需與桌面模擬區分。

## 內容與動畫的關聯模型

每一幕不是單獨的裝飾背景，而是同一筆里程碑資料的視覺層。新增或改動時必須同時理解下列關係：

1. `date` 與 `content` 決定事件事實；不得用動畫新增可見敘事文案或改寫事件。
2. `section` 決定年份選單與時間位置；`tone` 只控制 SVG 載入前的深色 HTML 備援，不等於完整動畫色盤。
3. `asset` 指向 `assets/animations/` 內實際播放的本地 SVG；`animation` 記錄這份 SVG 為何如此設計、畫面如何演出及如何循環。
4. `contentRelationship` 必須明說事件中的哪個動詞、場所、物件或情緒被轉譯成畫面，避免只因年份相近就套用通用圖示。
5. `script` 是一段完整的畫面描述；`composition` 說明主體、前中後景與手機裁切；`storyBeats` 說明時間中的事件順序。
6. `style` 與 `palette` 保存視覺語彙；`timing`、`direction`、`camera`、`motionLayers`、`loop` 保存可實作與驗證的運動規格。

## 新增里程碑時的動畫創作流程

未來新增一筆里程碑時，先完成資料與動畫構想，再製作 SVG。不得先複製上一幕只換顏色。

1. **抓出事件事實**：只從 `content` 找出人物、場所、行為、旅程方式、具體物件與時間感。例如「觀看作品」和「登台演出」必須採不同觀看位置。
2. **選一個核心動詞**：如走入、穿越、等待、練習、觀看、返回、交錯、靠近。核心動詞要能連續播放，而不是只能出現一次的靜態結果。
3. **建立視覺隱喻**：用事件內已有的場所或物件放大情緒。例如邀請以推動紙張的風表現，返台以車窗內外的相對運動表現；隱喻不可變成新的可見文案。
4. **避免與相鄰幕重複**：比較前後兩幕的主體、幾何、方向、視角、速度與主色。至少在主體類型、主要方向、鏡頭視點、空間幾何四項中的兩項做出明顯差異。
5. **先畫手機構圖**：以 390×220 的中央裁切為基準，主體進入主要動作時必須可辨識；再向 360、430 與桌面延伸。重要動作不能只發生在桌面兩側。
6. **設計三層以上運動**：至少有一個線性穿越層、一個非線性身體／環境層，以及一個建立深度的遠景或近景層。不要用整張 SVG 一起漂移取代分層。
7. **寫出時間節拍**：以一個主週期分成建立空間、主體進場、核心動作、離場／接回四段；若是窗景等無單一主角場景，可改寫成遠、中、近、固定參照四種同時運動。
8. **先決定循環藏點**：主體應在畫外重設；重複地景必須等寬；粒子與燈光首尾透明；固定物件的局部旋轉不可覆蓋其定位 transform。
9. **保留文字可讀性與降級**：畫面本身需能被 40–45% 暗層覆蓋後仍可辨識；減少動態與列印使用 index.html 的靜態備援，不可依賴 SVG 最後一幀。
10. **把創意寫回資料**：完成 SVG 的同一次修改中，必須填齊 `animation` 所有欄位，並更新本文件、CURRENT_STATUS.md 和 CHANGELOG.md；沒有寫下設計理由的動畫不算完成。

## 創意一致性與差異化

- 全站共同語彙是暗底日系平面海報、清楚剪影、有限色盤、水平與垂直複合運動，以及安靜但持續的前進感；共同語彙不代表每幕都使用同一角色或同一路徑。
- 可延續的手法包括：固定消失點、遠慢近快視差、鏡像或反向人物、畫外進出、等寬地景、局部擺動、粒子淡化、光束掃動。
- 新創意應優先來自新事件的具體內容：若新里程碑涉及排練，可改用呼吸、群體節奏、道具傳遞或空間隊形，不必再畫另一個左至右單人；若涉及旅行，可使用月台、窗影、行李、航線高度或時間差，不必再畫另一架飛機。
- 禁止以獎盃、勾勾、一般時間軸節點、發光文字、巨大中央圖示或與事件無關的抽象掃光充當完整場景。
- 相鄰場景的主體方向和底色應有差異；橘／紅橘可以保留或新增，但需服從事件與整體有限色盤，不作無理由的高飽和裝飾。

## 驗證狀態

修改前：11 幕均可持續播放，但京都鳥居、吊鍋、盆栽及滾筒有定位覆蓋；粒子／地景存在可见重設。逐幕13秒（合計143秒）本機 Edge 測試無腳本錯誤，rAF 間隔約17ms，並非手機實機掉幀保證。
修改後驗證結果及 GitHub 發布狀態統一記錄於 CURRENT_STATUS.md。

## 新場景完成條件

- `data/milestones.json` 的事件事實、`assets/animations/` 資產路徑與完整 `animation` 欄位齊全，JSON 可解析。
- SVG 為本地 `1440×800`、無腳本、無外部圖片或網路引用；所有需要持續的 SMIL 節點為永久循環。
- 主體、背景和環境至少三層運動，包含水平與垂直成分、線性與非線性成分。
- 循環接點在至少兩個連續週期內不可見；transform 分層不覆蓋定位。
- 360、390、430px 手機裁切與桌面延伸均保留主體；文字開啟後仍可閱讀，頁面無水平溢出。
- 減少動態、無 JavaScript 與 A4 列印仍能閱讀日期和內文，靜態備援與新事件相符。

# 十一幕動畫製作規格與分鏡

最後更新：2026-09-22

本文件是全站 11 個里程碑 SVG 動畫的長期製作依據。它記錄資產對應、時長、移動方向、運鏡、分鏡節拍、色彩、循環方式與完成狀態。任何 AI 或協作者在修改動畫前，都必須先閱讀本文件；若使用者提出新指示，先更新本文件，再修改 SVG 與相關狀態文件。

## 全域製作規則

- **手機優先：** 每幕使用 `viewBox="0 0 1440 800"`，先以 360px、390px、430px 寬度的實際裁切檢查焦點、安全區與辨識度，再確認桌面延伸。
- **全屏動態與空間穿越（田中いずみ獨立動畫美學）：** 摒棄「單一物件置中、微幅呼吸」的靜態設計。每幕必須具備**主體橫跨全螢幕的穿越、跟拍攝影機平移、縱深俯衝或多層視差位移**，呈現生動、流暢且具電影感的情緒流動。
- **持續播放：** 動畫從頁面載入後便持續運行，不以捲動進入、離開或 `.is-current` 狀態重啟。所有 `<animate>` 與 `<animateTransform>` 一律使用 `repeatCount="indefinite"`。
- **輕快節奏：** 動畫主週期全面調整為 3.5—10 秒的靈活節奏，動作乾淨俐落、具現代感。
- **多層視差結構：** 每幕至少包含遠景（緩慢移轉 8–12s）、中景主體（橫向／斜向穿越 4–8s）、前景遮擋／動態細節（高速掠過 1.5–3s），營造豐富空間層次。
- **色彩與區隔：** 介面維持暗底，動畫可使用靛藍、鈷藍、青綠、紫灰、冷黃白、苔綠等事件專屬色。禁止橘色與紅橘色；相鄰兩幕的主底色必須明顯不同。
- **技術限制：** 使用本地純 SVG 與 SMIL，不加入腳本、外部圖片、外部連結或昂貴濾鏡。`prefers-reduced-motion` 與列印模式由 `index.html` 的靜態備援處理。

## 批次與驗收

全站 11 幕 SVG 均已在本地完成全屏動態、多層視差、人物穿越與攝影機平移之全面重製。11 份檔案全部通過 XML 結構驗證、原生 SMIL 動畫節點全部確保 `repeatCount="indefinite"`，無外部腳本或違規引用。主週期全面調整至 4–10 秒內的生動靈活節奏，相鄰場景之色盤徹底獨立區隔。
驗證時執行：XML 解析、SVG 安全性檢查、全部動畫節點無限循環檢查，以及 HTML 標籤配對檢查與嵌入腳本語法檢驗。

# 設計系統

## 設計方向

網站採用「日系動畫作品集 × 滿版文字場景」。手機優先，參考 Izumi Tanaka 網站的全視窗首屏、固定輕量導覽、大量留白與連續滿版內容，但不複製其圖像或程式碼。

## 視覺原則

- 網站介面維持暖白、近黑與冷調薄荷綠；11 個里程碑動畫統一使用暗底，不使用橘紅。
- 全站改用無襯線字體。標題與正文使用 Noto Sans TC，年份使用 Montserrat。
- 事件使用直接相接的滿版場景；桌面只增加日期與內容的橫向層次，不改成交錯時間軸。
- 不使用卡片、圓角、陰影或背景紋理。每個里程碑使用一張與事件直接相關的本地滿版 SVG 動畫場景，作為內容的一部分而非裝飾圖示；減少動態與列印模式才使用原有 inline SVG 靜態備援。
- 11 幕共用日系電影動畫語彙：乾淨幾何輪廓、前中後景視差、人物表演與有目的的虛擬運鏡。可依事件使用靛藍、青綠、紫灰、鈷藍、冷黃白等較豐富色彩，但不使用橘紅，也不直接臨摹任何動畫作品的角色、分鏡或素材。
- 各 SVG 可依事件建立較豐富的色彩腳本；相鄰兩幕必須在底色的色相或明度上有清楚差異。HTML 載入備援仍以墨藍黑 `#111923` 與深灰綠 `#20313b` A／B 交錯，避免資產載入前出現同色相連。
- 2017、2018/09—2020/03、2019/01 與 2019 / Summer 分別呈現暗林恐龍、夜航、深夜廚房與夏季排練室；四幕與後段使用相同色盤、線條密度及多層移動方式。
- 2018/09—2020/03 使用 32 秒右至左的連續夜航；飛機保持同一條空間軸線，攝影機以跟拍、傾斜、推近與俯看改變景別，最後由近景雲層遮住循環接點。不得在畫面中停留或因不同動畫軌道而頓挫。
- 里程碑文字只能來自 `CONTENT_SOURCE.md`。

## 互動

- 所有尺寸使用固定站名、右上角漢堡按鈕與全螢幕年份選單。
- 分享時使用獨立的 `access.html` 極簡四碼入口，不重複顯示站名；「四位數密碼」以淡色 placeholder 放在輸入框內，輸入正確後前往唯一主要網站 `index.html`。主要網站本身不再內嵌密碼遮罩。
- 手機首屏高度為 `20svh`（最低 120px），桌面為 `25svh`（最低 180px）；`SCROLL` 直向字（`writing-mode: vertical-rl`）搭配動態細線引導捲動，位置精準設定為「中間靠左」（手機 `margin-left: clamp(32%, 36vw, 40%)`、桌面 `margin-left: clamp(30%, 34vw, 38%)`），徹底避開固定頂部站名「龔龔里程碑」（X ≈ 20–100px），滑動時絕不重疊。
- 所有里程碑內文使用置中文字層：無背景、無外框、無模糊方形框，純透明懸浮。文字為純白（`#ffffff`），搭配多層高對比文字陰影（`text-shadow`）形成清晰光暈輪廓，徹底杜絕被背景動畫光影吃色的問題。
- 月份／年份字型調小（`clamp(.75rem, 2.4vw, .88rem)`），作為低調精緻的元數據標題；內容正文字型調大（`clamp(1.12rem, 4.2vw, 1.38rem)`），行高寬鬆（1.72），給予舒適的閱讀體驗。
- 桌面滾動進入場景（`.is-current`）與手機點擊展開（`.panel-open`）時，全場景背景微幅暗化（`rgba(0, 0, 0, .40–.45)`），純白文字高反差浮現。
- 2024/09—2025/05 於老師引言移除後，已全面回歸與其他 10 個里程碑完全相同之置中單欄 `.event-body` 前景面板結構，維持全站視覺節奏的一致與和諧。
- 所有滿版 SVG 從頁面載入後持續播放，不使用捲動觸發的背景進場、出場或重播。每幕至少包含三個不同速度的動態層：背景或遠景持續橫移、主題人物／物件完整穿越畫面、前景線條或空氣元素進行垂直或斜向移動。不可只讓中央物件原地旋轉、縮放或呼吸，也不以共用掃光取代場景本身的運動。
- 全站動畫以 4—10 秒為靈活主週期，主體具備明確穿越（橫越全屏、縱深俯衝、側空翻等）與多層視差。所有 `<animate>` 與 `<animateTransform>` 必須設定 `repeatCount="indefinite"`，循環接點發生在畫外或遮擋之下。
- 相鄰場景的主體運動方向交錯使用，底色色盤明顯區隔。
- 里程碑內容區不使用分隔橫線。
- 2020/03—2023/11 使用沿海鐵道疾馳與海浪構圖，承接「疫情爆發，回到台灣」。
- 2020/02 使用舞台大幕拉開、雙聚光燈大角度交錯橫掃構圖。
- 全站壓軸最終場景為獨立的 `Shitty but proud.`，大字居中，背景搭配晨曦行者大步飛奔動畫。
- 旅程點、太陽、波浪、洗衣機滾筒等可有低強度循環動態，但不得干擾閱讀。
- 文字前景可在離開視窗後重置淡入狀態；外部 SVG 背景不可暫停、退場或重新起播，必須從頁面載入後持續運行。
- `prefers-reduced-motion` 時停用動畫並直接顯示完整插圖及內容；列印模式同理。
- 場景保留鍵盤焦點、觸控與 A4 列印支援。

## 響應式

- 動畫構圖以 360px、390px、430px 手機寬度為第一基準；人物、交通工具及事件辨識物在手機裁切後仍須可辨識，桌面僅向左右延伸更多景物，不改變主題焦點。
- 360px 起使用精簡首屏及滿寬事件場景；短事件高度為 `max(26svh, 200px)`，內文字級不小於 16px。
- 760px 起放大滿版插圖與內容留白，但仍使用漢堡選單並維持單向閱讀。
- 760px 起首屏使用 `25svh` 且不低於 180px；事件場景為約 `82svh` 且不低於 620px。
- 桌面內容最大寬度 1160px，正文最大寬度約 608px。
- `html`、`body`、固定導覽、選單及內容容器不得超過視窗寬度；長文字必須安全換行。
- 滿版 SVG 同時受視窗寬度與高度限制，必須完整留在自身場景及可視範圍內；事件內容留白需包含裝置安全區。

# 專案需求書

> 本文件由原始的 `20260921_一開始的prompt.txt` 整理而成。內容保留原意，僅改為較容易維護的 Markdown 結構。

## 專案目的

製作一個「人生里程碑時間軸」單頁網站，作為送給朋友的禮物。作品需同時兼顧美感、溫度、手機閱讀與實體列印。

## 交付格式

- 主要網站仍由單一 HTML 實作；2017、2018/09—2020/03、2019/01 與 2019 / Summer 場景依後續指示使用同目錄的本地 SVG 動畫資產。
- CSS 與 JavaScript 全部寫在同一個 HTML 內。
- 每個里程碑皆可使用同目錄的本地 SVG 動畫資產；這些檔案不得包含腳本或外部網路引用，並須保留減少動態與列印備援。
- 每個里程碑目前皆使用一張本地外部 SVG 動畫；內嵌 SVG 僅作為減少動態與列印模式的靜態備援。
- 字體使用 Google Fonts 的 Noto Sans TC、PT Sans 與 Montserrat，並設定系統備援字體。

## 使用情境

### 手機閱讀

- 以 mobile-first 設計。
- 最小支援寬度為 360px。
- 手機上的文字至少 16px，並維持舒適行距。

### A4 列印

- 提供 `@media print` 樣式。
- 列印時取消動畫及捲動浮現，直接顯示全部內容。
- 使用 `print-color-adjust: exact` 保留必要背景色。
- 深色背景於列印時轉成淺色，以節省墨水。
- 每個事件節點使用 `break-inside: avoid`，避免內容跨頁斷裂。
- 版面需適合 A4 直式紙張。

### 圖像策略

- 目前沒有照片。
- 版面以文字、日期、留白、色塊與事件專屬的內嵌 SVG 線性插圖為主。
- 不預留照片位置。

## 內容與語言

- 頁面標題為「龔龔里程碑」。
- `Shitty but proud.` 為全站壓軸最終場景；不另設結語頁尾。
- 第一階段只使用繁體中文；英文版本不在目前範圍內。
- 結構化里程碑內容位於根目錄 [`milestones.json`](../milestones.json)，可讀對照請參考 [`CONTENT_SOURCE.md`](./CONTENT_SOURCE.md)。

## 版面與視覺

- 使用由上而下的單向時間軸，以直接相接的全寬文字場景呈現；手機短事件約為四分之一視窗高，滿版動畫上疊置中文字，內容較長時自然增高，不得裁掉內容。
- 手機與桌面都使用固定站名、右上角漢堡按鈕及全螢幕年份選單。
- 不加入原始內容以外的章節標題、事件標題、銜接文字或口號。
- 不使用裝飾圖示、卡片或背景紋理；文字陰影保留作閱讀輔助。
- 整體需溫暖、有質感且簡約，使用近黑、暖白與單一冷調薄荷綠強調色；里程碑動畫保留獨立暗底配色，現有橘／紅橘色已獲使用者於最終驗收接受。

## 互動

- 以單次 rAF 合併捲動更新，搭配進入／離開雙門檻顯示桌面文字；手機以原生按鈕展開。
- 每個事件的外部 SVG 從頁面載入後持續播放；內嵌備援才使用靜態描邊圖形。
- 插圖採滿版構圖且不與捲動狀態綁定；桌面文字在場景進入主要視區後顯示，手機點擊展開；減少動態及列印直接顯示。
- 網站由 `index.html` 直接公開，不設密碼入口。
- 不使用大型 JavaScript 套件。
- 尊重 `prefers-reduced-motion`；使用者關閉動畫時直接顯示內容。
- 不需要後端、登入或資料庫。

## HTML 與維護品質

- 使用 `<html lang="zh-Hant">`。
- 加入正確的 viewport meta。
- 色彩集中於 CSS `:root`；內容結構使用語意化 class，並由文件說明修改方式。
- 成品必須能直接以瀏覽器開啟。

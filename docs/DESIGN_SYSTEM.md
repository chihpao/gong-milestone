# 設計系統

最後更新：2026-09-22，最終驗收版。

## 視覺與內容

- 手機優先，360px 起；暖白、近黑、薄荷綠介面，11 幕獨立暗底 SVG。使用者已接受現有橘／紅橘色，保留各幕原色。
- 正文 Noto Sans TC；日期 PT Sans；選單及英文 Montserrat。Google Fonts 以系統字型備援。
- 里程碑日期與文案由 `data/milestones.json` 載入，並與 CONTENT_SOURCE.md 及 HTML 靜態備援同步；保留使用者的 2019/01 合併句。2024 課程為單欄，不恢復已刪除引言或祝福。
- 文字置中、白色、透明背景；無文字框、無背景模糊，文字陰影用於閱讀對比。
- 每幕日期、文案、`assets/animations/` 資產及完整動畫腳本綁在 `data/milestones.json`；共同創作方法、方向、時序與循環規則以 ANIMATION_STORYBOARD.md 為準。

## 尺寸

- 手機首屏20svh／最低120px，桌面25svh／最低180px；SCROLL 位於偏左中央。
- 手機場景最低 max(26svh,200px)，長內容自然增高；760px 起最低 max(82svh,620px)。
- 正文面板最大38rem，手機字級 clamp(1.12rem,4.2vw,1.38rem)，桌面 clamp(.92rem,1.05vw,1.05rem)。
- 安全區內距、長字換行及容器寬度限制保留。

## 互動

- 固定站名與44px漢堡按鈕；年份選單手機由頂部開始，桌面可用空間充足時置中，短視窗可捲動。
- 選單開啟保存捲動位置並固定 body；背景 main 與站名 inert。焦點移至第一個年份，Tab 在選單／關閉按鈕間循環，Escape 關閉並回復按鈕焦點。
- 選取年份後回復背景，焦點移至該段落並進行錨點跳轉。
- 手機場景以覆蓋全幕的原生 button 開關文字，Enter／Space 沿用原生操作；提供 aria-expanded、aria-controls 與可讀名稱。一次只展開一幕。
- 桌面以可見高度38%進入、22%離開判定文字顯示，避免邊界抖動；比例相對可用視窗計算，短視窗仍可顯示。
- 文字面板淡入0.4–0.45s、位移0.5–0.6s；手機位移24px，桌面18px；桌面段落間隔0.08s。
- 一次性 rAF 合併捲動／尺寸事件，無持續JS動畫迴圈，也不依賴 IntersectionObserver。
- 外部 SVG 載入後持續播放，文字、選單與捲動不會重新載入 SVG。

## 降級與列印

- 減少動態直接顯示全部文字、關閉面板按鈕，以薄荷綠靜態插圖替代外部 SVG。媒體偏好變更即時同步。
- JavaScript 關閉時文字仍可讀。
- A4直式、13mm邊界；白底黑字、無首屏空白、無導覽、無文字陰影或動畫；插圖與正文兩欄，單幕避免跨頁切開。
- 網站直接公開，不設密碼入口；JSON 無法載入或 JavaScript 關閉時仍顯示 HTML 靜態備援。

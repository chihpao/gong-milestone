## 現行視覺方向

參考網站：https://www.izumi-tanaka.com/

取用的是手機版的設計原則，不是照抄：

- 手機使用精簡留白首屏，桌面保留全視窗首屏。
- 輕量固定導覽。
- 所有尺寸使用右上角漢堡按鈕與全螢幕年份選單。
- 內容直接相接，不使用卡片容器。
- 簡潔無襯線排版與少量動態。
- 每個事件都有一張抽象線性 SVG 插圖；線條沿用場景文字色，不增加新的色彩或外部圖像資源。

目前色彩為：

- 暖白：`#fbfaf6`
- 近黑：`#111311`
- 薄荷綠：`#71dfc2`
- 深薄荷綠：`#147966`

使用者明確不喜歡橘紅色，後續不得恢復橘紅色。

## 技術架構

- 原生 HTML、CSS、JavaScript。
- 所有網站程式均內嵌於單一 HTML。
- 沒有 npm、建置步驟、前端框架或動畫套件。
- 沒有後端、登入、資料庫或分析工具。
- 唯一外部依賴是 Google Fonts：Noto Sans TC 與 Montserrat。
- 以 `IntersectionObserver` 控制文字淡入、SVG 描邊動畫與目前區段狀態。
- 以少量原生 JavaScript 控制選單、閱讀進度與固定導覽狀態。

使用者允許未來加入前端框架或動畫套件，但只有在新的功能確實需要時才應加入。現有需求使用原生技術已足夠。
